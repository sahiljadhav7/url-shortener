Reference

Glossary

The canonical words for this project. Only terms you've already reasoned through go in here.

Design

Hot path
The code path that handles most of the traffic. Here, the redirect, at about 100 reads per write.
Avoid: fast path, main route
Base62
The alphabet a–z A–Z 0–9. Every character passes through a URL unchanged, unlike Base64's + and /.
Atomic counter
A number incremented by the database in one operation (UpdateItem with ADD), so concurrent callers never get the same value.
Avoid: auto-increment, global variable
Scrambler (bijection)
A reversible one-to-one mapping from counter value to code. It looks random but can never collide.
Avoid: hash (hashes can collide)

AWS

Stateless function
A Lambda keeps nothing reliable in memory between calls. All state lives in a database.
Partition key (PK)
The attribute DynamoDB uses to find an item directly. code for Links, id for Counter.
Avoid: primary ID, index
SAM template
template.yaml: one file that declares every function, table and route. Deployed as one stack.
Avoid: config file

HTTP

302 Found
A temporary redirect to the URL in the Location header. Not cached by default, so every click reaches the server.
410 Gone
The resource existed and has been removed for good. Used for expired links.
