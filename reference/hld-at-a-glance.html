Flows

POST /shorten (write)

User → API Gateway → Shorten Lambda → UpdateItem ADD 1 Counter → scramble (Base62, 7 chars) → PutItem Links → short URL back.

GET /{code} (read · hot path · ~100× the writes)

User → API Gateway → Redirect Lambda → GetItem Links → 302 + Location header. 410 for expired links (Phase 3). Async click ADD to Clicks (Phase 4).
